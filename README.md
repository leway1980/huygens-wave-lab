## 模型邊界

- 繞射是連續開口的前向純量角譜（惠更斯積分等價表示），含倏逝項；域 8192 與 16384 的代表點複數場最大差約 0.001474。不含完整流體／電磁邊界反射。
- 水波使用各自的延遲相位；異頻黃線是移動的相位差零分支，並非固定中央亮紋。
- 薄膜採無吸收 Fresnel/Airy 反射率。A 為表面反射，B 為內部反射的合計複振幅；波形 A+B 與反射率來自同一計算。光路分開、膜厚放大畫，數值採正常入射。
- 油膜：空氣－油－水；皂膜：空氣－膜－空氣；牛頓環：玻璃－空氣－玻璃。零厚度時，皂膜及對稱玻璃夾層反射為零，油膜則回到空氣－水反射。
- 白光為等能連續波長加寬頻 RGB 感光近似，非 D65／校色照片。紅色偏強不等於其他色完全消失。左圖道路／球面陰影固定；右側色塊為未加陰影的模型色。
- 蜘蛛絲提供理想規則微滴及局部平膜概念模型；不能用來替所有蛛網照片定因。光碟為局部一維反射光柵，不含完整三維散射包絡。
- 聲速 343 m/s；車速 −200～200、人速 −120～120 m/s，正為向右。`f耳=f源(c−n v人)/(c−n v車)`，n 為延遲發聲處到人的方向。只有人移動時，空氣中的波長不變。
- 圖面統一慢動作，聲音用實際頻率。初始包含連續發聲穩態；快速比較／重新比較明確重開一輪。預設即時比較，波前與音高同時重建；勾選延遲才保留舊波與實際傳播時間。
- 光採視線方向相對論公式，β 正為遠離：`λ收到/λ發出=sqrt((1+β)/(1−β))`。光源移動視角包含 γ 發光週期；光源靜止視角不因船移動而壓縮波前。光譜數值是船上尺鐘量得。
- 白光恆星用 5778 K Planck 光譜移動並正規化亮度，不模擬完整色度、相對論增亮或宇宙膨脹紅移。超出可見光的參考波前用灰色示意。

## 2026-11-04：戰鬥機掠空、音爆與馬赫角
- 新情境 `#jet`：側視戰鬥機、山景、固定地面觀察者與逐時發出的圓形波前。可調 0.30–2.40 M、高度 600–1200 m、原音頻率、動畫速度與音量，含暫停、單步、重飛。
- 均勻靜止空氣 c = 343 m/s，等速水平飛行。每個波前以歷史發聲位置為中心；馬赫半角 μ = asin(1/M)，錐面掃過地面測點時才播放每趟一次的合成音爆。
- 音爆抵達位置 x = h sqrt(M²−1)，時間以通過正上方為零。1.6 M、1000 m 的例子約 2.276 s 後抵達。
- 透過延遲時間方程求耳邊音調。亞音速只有一路；超音速錐面前無聲，之後可有兩個發聲時刻的抵達波，音調圖與兩路音訊使用同一結果。近焦散處的無限頻率是理想點源模型的奇異性，播放限制為 50–3500 Hz。
- 馬赫錐是弱擾動／弱激波教學近似，未模擬機形決定的有限強度激波、地面反射或大氣折射。人物放大，接收位置以腳下地面黃點表示；圖上的波前稀疏取樣，音調與短 N 形音爆皆為教學合成。
- 參考：NASA Mach Angle（https://www.grc.nasa.gov/WWW/K-12/airplane/machang.html ）與 Sound Wave Applet（https://www.grc.nasa.gov/www/k-12/airplane/sndwave.html ）。
- 驗證：1004 項既有物理斷言、16 情境 142 項操作檢查、`jet-check.cjs` 467 項延遲時間／馬赫幾何／音爆與音訊節點檢查；原生 Canvas 繪圖與 Chrome 實際頁面、控制與 Web Audio 啟用驗證。未以麥克風量測喇叭輸出。
